## About This Repository

Welcome! This repository contains my hands-on projects developed as part of the **CodeAlpha Cyber Security Internship**.

The projects demonstrate practical learning across three areas of cybersecurity:

1. Security awareness and phishing education
2. Network traffic monitoring and packet analysis
3. Rule-based network intrusion detection

Each project has its own folder, source code, documentation, and supporting resources where applicable.

## Project Portfolio

### 1. Phishing Awareness Training

An interactive educational website that helps users understand phishing attacks and recognize common social-engineering warning signs.

**Key features**
- Overview of common phishing types
- Practical checklist for identifying suspicious messages
- Simulated phishing email with highlighted red flags
- Explanation of social-engineering tactics
- Interactive quiz with feedback and score tracking

**Technology:** HTML5, CSS3, JavaScript

[View Project 1](./Project-1-Phishing-Awareness)

### 2. NetSniffer - Basic Network Sniffer

A Python-based network monitoring application that captures packets and displays useful traffic information through a web dashboard.

**Key features**
- Live packet capture
- Source and destination IP visibility
- TCP, UDP, and ICMP protocol identification
- Port and packet-size information
- Dashboard controls to start, stop, and clear capture data

**Technology:** Python, Flask, Scapy, Npcap, HTML, CSS, JavaScript

[View Project 2](./Project-2-Network-Sniffer)

### 3. SentinelNIDS - Network Intrusion Detection System

A web-based, rule-driven network intrusion detection project designed to monitor packet activity and highlight potentially suspicious behavior.

**Key features**
- Live packet monitoring
- Rule-based port-scan detection
- SYN burst and ICMP burst indicators
- Alert severity classification
- Dashboard for packet activity and security alerts
- SQLite-based alert storage
- Offline threat simulation for testing detection rules

**Technology:** Python, Flask, Scapy, SQLite, HTML, CSS, JavaScript, Npcap

[View Project 3](./Project-3-Network-Intrusion-Detection)

> **Note:** Detection alerts are indicators generated by configured rules. They are not, by themselves, proof that a real attack has occurred.

## Getting Started

Each project has its own dependencies and run instructions. Open the relevant project folder and follow its README.

For the Python-based projects, a virtual environment is recommended:

```bash
python -m venv venv
```

**Windows Command Prompt:**

```cmd
venv\Scripts\activate
```

Then install the dependencies listed in that project's `requirements.txt` file, if provided.

For packet-capture projects on Windows, Npcap may be required. Run packet capture with the permissions required by your operating system and setup.
